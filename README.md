# TRSProject

Android app with live call transcription. An Android client streams microphone
audio to a Kotlin/Ktor backend over WebSockets; the backend forwards the audio
to Google Speech-to-Text and relays live transcripts back to the client.

New to the project? Start here: **[SETUP.md](./SETUP.md)**

## How to build & run app
1. Go to File > Open 
2. In the file system, select to TRSandroid/android/app
3. Once that folder is opened in the window, click the run button in the upper right corner
